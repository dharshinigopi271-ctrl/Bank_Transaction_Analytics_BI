# 🏦 Bank Transaction Analytics Dashboard

## 📌 Overview

The **Bank Transaction Analytics Dashboard** is a Power BI project designed to monitor and analyze banking transactions through interactive KPIs, financial trends, cash-flow analysis, transaction categories, and anomaly monitoring.

## 📊 Key KPIs

* Total Transactions
* Total Deposit
* Total Withdrawal
* Average Balance
* Total Anomalies

## 📈 Dashboard Analysis

The dashboard provides analysis of:

* Monthly transaction trends
* Monthly cash flow
* Transaction type distribution
* Deposit vs. withdrawal trends
* Top 10 transaction categories
* Balance trends
* Anomalous transactions

## 🗂️ Data Model

The project uses two tables:

1. **Bank_Transaction_Analytics_Final** – Transaction fact table
2. **Calendar** – Dedicated date table

The Calendar table supports accurate date-based and monthly analysis.

## 🛠️ Tools Used

* Microsoft Power BI
* DAX
* Power Query
* Data Modeling
* Data Visualization

## 🎯 Project Objectives

* Analyze banking transaction activity
* Monitor deposits and withdrawals
* Track account balance trends
* Identify transaction patterns
* Monitor potential anomalies
* Create an interactive financial analytics dashboard

## 📁 Files

* `Bank_Transaction_Analytics_Final.xlsx`

## 📌 Conclusion

This project demonstrates the use of Power BI, DAX, data modeling, and visualization techniques to transform bank transaction data into an interactive analytics dashboard for financial monitoring and reporting.
